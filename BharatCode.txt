Project Name: EchoMind
Category: Work & Automation
Description: AI-powered project memory and context recovery engine. EchoMind turns scattered project notes, messy thoughts, and raw task dumps into structured project state, decisions, blockers, risks, and prioritized next actions.
Target Audience: Solo developers, students, freelancers, and knowledge workers juggling multiple projects.
Core Stack: React, Vite, Tailwind CSS, Node.js, Express, BharatCode Sovereign Model API
Submission Declaration: This repository is an official submission for the BharatCode Hackathon (BharatCode Build League).
Model / API Usage: Integrates BharatCode Model API for structured project memory extraction following a strict deterministic JSON schema.
